# 🛡️ Школьный Бот-Модератор для классного чата (без учителя)

Telegram-бот для автоматической модерации и поддержания порядка в классном чате по бальной системе репутации и правил.

---

## 📜 Правила модерации

1. **Стартовый капитал**: Каждому участнику чата автоматически начисляется **10 очков**.
2. **Мат (-1 очко)**: За использование нецензурной лексики списывается **1 очко**, выдается предупреждение с остатком баланса, а матерное сообщение удаляется.
3. **Спам и флуд (-1 очко)**: За частую отправку сообщений (более 4 сообщений за 4 секунды), повторение одного и того же текста или скам-ссылки списывается **1 очко**, спам удаляется.
4. **Обнуление очков (Мут на 3 часа)**: Если участник теряет все 10 очков (баланс $\le$ 0), он отправляется в **мут на 3 часа**, после чего баланс восстанавливается до 10.
5. **Оскорбления участников (Мут на 2 часа)**: За прямое или агрессивное оскорбление одноклассников участник мгновенно отправляется в **мут на 2 часа**, сообщение удаляется.

> [!TIP]
> **Поддержка чатов, где все участники — администраторы:**
> В Telegram Bot API бот не может выставить стандартный запрет (`restrictChatMember`) пользователю с правами админа. Поэтому в боте реализован **умный виртуальный мут**: если нарушитель является администратором, бот фиксирует срок мута в базе данных и **автоматически удаляет любые новые сообщения нарушителя**, пока не истечёт время наказания (2 часа за оскорбление или 3 часа за потерю всех очков). Мут работает безотказно для всех!

## ⚡ Команды бота

### Для всех участников:
- `/rules` (или `/правила`) — просмотреть актуальные правила чата (включая бонус вежливости +1 балл за каждые 25 сообщений без мата).
- `/score` (или `/баллы`, `/очки`) — узнать свой текущий баланс очков, количество сообщений без мата (прогресс до +1 балла) и количество нарушений.
- `/top` (или `/leaderboard`, `/рейтинг`) — таблица самых вежливых участников класса.

### Команды администраторов (доступны ТОЛЬКО вам, ID: 5325601154 и 1287790358):
- 📸 **Доказательства и скриншоты**:
  - `/proof @username` — получить чистый скриншот последнего нарушения участника.
  - `/proof [номер]` — получить скриншот конкретного нарушения по ID записи.
  - Ответом на сообщение нарушителя: `/proof`.
  - Автоматическая отправка: при любом нарушении скриншот моментально отправляется вам в ЛС.
- 🎁 **Пополнение очков (лимит максимум 10 очков)**:
  - `/plus @username [N]` или `/пополнить @username [N]` (или `/addpoints`) — добавить N очков участнику.
  - В ЛС с ботом: `@username +1` или `@username +5` — быстрое пополнение прямо в личке!
  - Ответом на сообщение в группе: `/plus [N]` или `/пополнить [N]`.
- 📉 **Списание очков**:
  - `@username` или `@username -1` в ЛС с ботом — быстрое списание очка.
  - `/warn @username [N] [причина]` (или `/minus`) — снять очко(и) по юзернейму или ответом на сообщение.
- 🔓 `/unmute [@username/id]` — снять мут с участника.
- 🔄 `/resetpoints [@username]` — сбросить очки участника до начальных 10.

## 🚀 Установка и запуск

### 1. Требования
- Python 3.9+ (рекомендуется Python 3.11 - 3.14)
- Токен Telegram бота от [@BotFather](https://t.me/BotFather)

### 2. Клонирование репозитория
```bash
git clone https://github.com/tonipogozhev1234-coder/school-chat-moderator-bot.git
cd school-chat-moderator-bot
```

### 3. Настройка виртуального окружения
```bash
# Windows
python -m venv .venv
.venv\Scripts\activate

# Linux / macOS
python3 -m venv .venv
source .venv/bin/activate
```

### 4. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 5. Настройка токена бота
Скопируйте файл `.env.example` в `.env`:
```bash
# Windows (PowerShell)
Copy-Item .env.example .env

# Linux / macOS
cp .env.example .env
```
Откройте `.env` и укажите ваш токен:
```ini
BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyz
```

### 6. Добавление бота в чат
1. Создайте группу класса в Telegram.
2. Добавьте в неё вашего бота.
3. **ВАЖНО**: Назначьте бота **Администратором группы** и дайте ему права:
   - ✅ **Блокировка пользователей** (Restrict members) — необходимо для выдачи мута.
   - ✅ **Удаление сообщений** (Delete messages) — необходимо для удаления мата и спама.

### 7. Запуск бота
```bash
python bot.py
```

## 🛠️ Настройки (.env)

| Параметр | По умолчанию | Описание |
|---|---|---|
| `BOT_TOKEN` | - | Токен Telegram-бота |
| `INITIAL_POINTS` | `10` | Стартовое количество очков |
| `MAT_PENALTY` | `1` | Списание очков за мат |
| `SPAM_PENALTY` | `1` | Списание очков за спам |
| `INSULT_MUTE_HOURS` | `2` | Часов мута за оскорбление |
| `ZERO_POINTS_MUTE_HOURS` | `3` | Часов мута при 0 очков |
| `DELETE_VIOLATING_MESSAGES`| `True` | Удалять сообщения с нарушениями |
